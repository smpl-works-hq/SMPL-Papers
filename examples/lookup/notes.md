# Lookup fixture

This synthetic example compares two fictional local lookup implementations on
one fixed dataset. Each run processes the same 10,000 keys. The unit is
milliseconds per run. The three rows are the only available observations.
Neither variance across datasets nor performance under concurrent load was
measured. Compare means and mention that the fixture is illustrative.

The supplied literature corpus is a fixed primary-source fixture for a
methodological definition. Use it for the test run without sending the inputs
to a web search service.
